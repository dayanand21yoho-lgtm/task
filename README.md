# Python & Data Engineering Assessment - Feature Branch

## Project Overview
This project contains Python programming, file handling, API integration, data analysis, and Git workflow tasks.

## Project Structure
- `data/` – Employee and department CSV files.
- `notebooks/` – Jupyter Notebook analysis.
- `reports/` – Generated charts and reports.
- `src/` – Python source code.

## Requirements
- Python 3
- NumPy
- Pandas
- Matplotlib
- Requests
- Python-dotenv
- Jupyter Notebook

## Setup Instructions
1. Clone the repository.
2. Create a virtual environment.
3. Activate the virtual environment.
4. Install dependencies using `pip install -r requirements.txt`.
5. Run the Python scripts from the project directory.

## Findings
1. Employee data was loaded and analysed.
2. Missing salary values were handled.
3. Duplicate employee records were checked.
4. Department-wise salary statistics were calculated.
5. Bar, histogram, scatter, and line charts were generated.
